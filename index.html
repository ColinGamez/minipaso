Minipaso

A Windows tribute to GOGA's legendary 2007 Minpaso Gadget for the Vista Sidebar. Same ritual: measure, vote, rank.

Download the app Source (C# 4 · VS2010)

How it works

  1. 測定 Measure — the app runs winsat formal (or reads your latest official assessment from C:\Windows\Performance\WinSAT\DataStore).
  2. 投票 Vote — pick a nickname and submit your six WEI subscores. Only scores + PC model + nickname leave your machine. The 2007 original also uploaded drive serials; this one doesn't.
  3. ランキング Ranking — the live table below, served from Cloudflare R2.

Build it yourself

Opens and compiles in Visual Studio 2010, zero extensions — C# 4, .NET 4.0, WinForms:

git clone https://github.com/ColinGamez/minipaso.git
start Minipaso.sln   & press F5

Then point Reporter.cs at your own worker if you self-host the leaderboard.
